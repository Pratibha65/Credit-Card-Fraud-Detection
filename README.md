# Credit-Card-Fraud-Detection

• This project involves the development of a credit card fraud detection system using python and machine learning techniques.
• The dataset consists of anonymized transaction data with features transformed via PCA for confidentiality. 
• The goal is to identify fraudulent transactions using a logistic regression model, which is well-suited for binary classification tasks. 
• The project begins with data preprocessing, including handling missing values and balancing the dataset through under sampling of legitimate transactions. 
• The cleaned data is then split into training and testing sets. 
• A logistic regression model is trained on the training data and evaluated on the test data to measure its accuracy. 
• The model's performance is assessed using metrics such as accuracy, precision, recall, and F1 score. 
• This approach aims to enhance the security of financial transactions by accurately identifying and preventing fraudulent activities.
